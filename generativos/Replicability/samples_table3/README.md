# Table 3 samples

The samples used in Table 3 of the main paper will be uploaded to the following Google Drive folder:

https://drive.google.com/drive/folders/1ilCFuFbfBObzQprOLV-_uE5kP3FivZgD?usp=sharing

Download the available checkpoints and place them in the corresponding subfolder inside `samples_tables3/`:

```text
samples_tables3/
├── DiT-3D/
├── DPM/
├── PVD/
├── SLIDE-3D/
├── SPVD-L/
├── SPVD-S/
└── XCube/
```

Each sample files should remain inside the folder of the baseline/model it belongs to.
