# Baseline Checkpoints

The baseline checkpoints will be uploaded to the following Google Drive folder:

https://drive.google.com/drive/folders/1ilCFuFbfBObzQprOLV-_uE5kP3FivZgD?usp=sharing

Download the available checkpoints and place them in the corresponding subfolder inside `Baselines_Checkpoints/`:

```text
Baselines_Checkpoints/
├── DiT-3D/
├── DPM/
├── LION/
├── PVD/
├── SLIDE-3D/
├── SPVD-L/
├── SPVD-S/
└── XCube/
```

Each checkpoint should remain inside the folder of the baseline/model it belongs to.
